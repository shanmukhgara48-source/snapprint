# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SnapPrint, please report it privately rather than opening a public issue.

- Email: megaralex1@gmail.com
- Include: a description of the issue, steps to reproduce, and the potential impact.

We'll acknowledge your report within a few days and follow up once the issue is triaged. Please give us reasonable time to fix the problem before any public disclosure.

## Scope

This covers the four subprojects in this repository: the Flutter mobile app (`snap_print/`), the FastAPI backend (`backend/`), the React admin dashboard (`admin-web/`), and the legacy Flutter admin prototype (`admin/`).

## Supported Versions

This project does not yet maintain multiple release branches — security fixes are applied to `main`.
